# Philosophy Visualizer
This project is a visualizer of the known concept that on Wikipedia, (almost) [all roads lead to Philosophy](https://en.wikipedia.org/wiki/Wikipedia:Getting_to_Philosophy).

## Aim
The aim of this project was to practice a bit of concurrency using Go with a concept that is "mildly interesting".

## Concepts encountered
Quite a bit of concepts were encountered while working on this project. For the sake of brevity, I shall only outine some of the concepts below:

- Communicating Sequential Processes
- Semaphores to bound concurrency
- SQLITE "sequential" write
- Token Bucket Algorithm
